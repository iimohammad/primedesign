# Next.js consumer example

From the repository root:

```bash
npm ci
npm run pack
npm install --prefix examples/next-app
node examples/next-app/node_modules/@primedesign/cli/bin/primedesign.mjs add button product-card --source --cwd examples/next-app
npm run build --prefix examples/next-app
npm run dev --prefix examples/next-app
```

This installs the real local npm tarballs and exercises CSS assets, server-safe Persian utilities, a server import of Button, client providers, ProductCard and DataTable. It does not rely on source aliases or workspace symlinks.

This consumer verifies a Server Component importing a copied source Button, a client-owned source ProductCard sharing package cart state, the data table, and the AI prompt package. Source files are generated by the installed tarball CLI, not linked to workspace source.
