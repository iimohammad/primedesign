# Plain HTML

Run `npm run build`, then open `/standalone/index.html` in the documentation server, or extract the browser download ZIP and serve it with any static HTTP server.

No React, npm install or framework project is required by a consumer of the browser bundle. The bundle includes its React rendering runtime internally so the same tested components behave consistently across environments. CSS and tokens are framework independent. See `docs/UNIVERSAL.md` for events, forms, Vue, Angular, Svelte and WordPress examples.
