# Architecture

PrimeDesign is an original implementation with ten independently packaged workspaces. It does not depend on Kashi.

`tokens` and `persian` are server-safe. `css` compiles token CSS, scoped resets, components and commerce styles into cascade layers. `icons` contains small SVG React functions. `react` is the common interactive layer. `forms`, `data`, `commerce` and `blocks` compose it without depending on any backend. `cli` generates application-owned facades rather than downloading or executing remote templates.

## Boundaries

- Provider state is local to its subtree. Theme, language, notification, cart, wishlist and comparison instances can coexist.
- Display values and canonical form values are separated for formatted Persian inputs. Dates use local calendar days and `YYYY-MM-DD`, avoiding midnight-to-UTC shifts.
- ICU/Intl is the Jalali conversion authority. Inverse conversion searches a bounded Gregorian range. Accepted Jalali input years are 1200–1600.
- Validation rules are shared by typed date entry, calendar selection, Today and range presets. Ranges crossing disabled days cannot be committed.
- Table server mode forwards state; it never re-sorts or slices a server response. Full server exports belong in `onExport`.
- Upload transport receives an `AbortSignal`; UI cancellation ignores late completion. Chunk transport retains acknowledged parts for retrying the same `File` object within the current page lifetime.
- Cart and wishlist are in-memory UI state. Persistence, tenant isolation, authorization, pricing and inventory locking belong to the application/server.

## Rendering and distribution

TypeScript emits ESM, declarations, declaration maps and source maps. Source files are included for debugging. Public exports use explicit `.js` relative paths and package entry points. Interactive entry points preserve `use client`; no bundler is allowed to strip it.

The docs are a static Vite application with no production API dependencies. Product art and fonts are local. The API explorer is generated by the TypeScript checker from actual runtime exports and their custom props. Packaging checks inspect npm tarball contents and required licenses.

## Quality

Vitest covers utility boundaries and DOM interactions. Playwright covers a real browser, desktop/mobile layouts, navigation, cart behavior, modal focus, RTL/LTR and axe checks. CI builds, typechecks, tests, checks packages and uploads browser failure reports. Supported React majors are exercised in a CI matrix.
