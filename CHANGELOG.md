# Changelog

## 0.2.0

- Add portable custom elements with bundled styles/font/runtime, provider scopes, typed JS property/event contracts, asynchronous callbacks and native form association.
- Add an installable WordPress plugin: sanitized generic shortcode, Gutenberg block, WooCommerce product cards and nonce-protected simple-product cart AJAX.
- Add offline editable source installation, source diff, search, doctor and a public JSON source registry.
- Add advanced layout/menu/content primitives, resizable panels, questionnaires, Kanban, team/preferences/settings blocks and detailed product/seller/coupon/bundle components.
- Add provider-independent AI UI: chat, prompts, attachments, sources, confirmations, tool calls, execution summaries, plans, queue/file tree/terminal/test results and SSE/NDJSON transport.
- Add standalone HTML example, browser/WordPress ZIP downloads, five documentation sections, an explicit shadcn coverage map and cross-platform browser/distribution tests.
- Preserve React 18/19 and Next.js client boundaries; make modal focus and outside-pointer logic work across Shadow DOM and slots.

## 0.1.0

- Original Persian-first design system with ten package workspaces and a static interactive documentation application.
- Scoped CSS, semantic light/dark themes, runtime brand/radius/density/font controls and self-hosted Vazirmatn.
- React controls, overlays, navigation, selection, Jalali calendars, localized inputs, upload queue and resumable chunk transport interface.
- Form state, validation, conditional schemas, field arrays, multi-step forms and allowlisted drafts.
- Data table with search, sorting, filters, selection, column controls, virtual rows, server mode and escaped CSV; charts with data tables.
- Five product card layouts, product merchandising cards, stock/variant actions, cart, wishlist, comparison, checkout and order UI.
- App shell, support inbox, messaging, notifications, pricing, authentication and file presentation blocks.
- Safe initializer/component facade CLI, generated API reference, unit and browser tests and CI.
